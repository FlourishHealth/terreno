The `terreno` plugin (Cursor and Claude Code) ships Grow/Pick/Roast/Brew/Taste as
`1-grow` … `5-taste`. Add the marketplace with `/plugin marketplace add FlourishHealth/terreno`,
install with `/plugin install terreno@terreno`, then invoke `/terreno:1-grow`.
Plugin version is `2.3.0`. Skills live under `plugins/terreno-planning/skills/`.
