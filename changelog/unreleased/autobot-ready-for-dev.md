Unattended agents can claim one unstarted `status:ready-for-dev` issue, run Grow
without a chat pause (assume answers unless a genuine human gate), then Pick ⇄
Roast, Brew, and Taste to a mergeable PR via the `autobot-ready-for-dev` skill.
Dashboard paste lives in that skill's `references/cursor-automation.md`.
`implement-ready-for-dev` still skips Grow and Taste and opens a draft PR.
