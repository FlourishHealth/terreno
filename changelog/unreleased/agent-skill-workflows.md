The Terreno planning plugin now uses vertical-slice TDD with boundary-only test doubles,
runs the full Bun suite in agent-quiet mode during Pour, verifies documentation, and adds
an independent standards/spec code review before opening a PR. Blend interviews in
grilling rounds and ends with a 15-line verify table. Grind is the single-feature short
path (research, task list, one TDD sub-agent per task). Architecture, roadmap-wayfinding,
and agent-document skills support deeper refactors and large efforts.
