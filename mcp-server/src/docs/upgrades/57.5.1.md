# Upgrading to 57.5.1

**Action required:** Yes
**Affected packages:** @terreno/api, @terreno/admin-backend, @terreno/jobs, @terreno/announcements, @terreno/mcp

## Summary

Bump every `@terreno/*` package together to `57.5.1`. This patch on the Expo SDK 57 line namespaces framework Mongoose models so they no longer collide with consumer `Notification`, `Membership`, and `Job` models, and moves the GitHub org, docs, and skill/plugin install URLs to `TerrenoLabs/terreno`. No Expo upgrade is required if you are already on `57.x`.

## Changed behavior

### GitHub org is TerrenoLabs

**What changed**

The repository is `TerrenoLabs/terreno`. Roadmap, package `repository` fields, docs links, and plugin/skill install commands point at that org. `FlourishHealth/terreno` URLs redirect.

**Why**

Terreno is its own GitHub organization.

**Migration**

```bash
# Before
git remote set-url origin git@github.com:FlourishHealth/terreno.git
npx skills add FlourishHealth/terreno
# /plugin marketplace add FlourishHealth/terreno

# After
git remote set-url origin git@github.com:TerrenoLabs/terreno.git
npx skills add TerrenoLabs/terreno
# /plugin marketplace add TerrenoLabs/terreno
```

Update bookmarks to `github.com/orgs/TerrenoLabs/projects/1` for the roadmap board.

### Framework Mongoose models use Terreno-specific names

**What changed**

Framework-owned models introduced in 57.3 and 57.4 now register as `Terreno*` names without changing MongoDB collections. Admin UI keys and `admin<ModelName>` RBAC resources keep the pre-namespace names. JWT recovery routes can be disabled with `authOptions.passwordReset`, `emailVerification`, and `legacyResetPasswordRoute`. `@terreno/api` exports `FRAMEWORK_MODEL_PUBLIC_NAMES` and `publicFrameworkModelName`.

**Why**

Generic Mongoose names such as `Notification`, `Membership`, and `Job` collided with consumer models on the default connection.

**Migration**

No MongoDB migration is needed: every model remains pinned to its existing collection. Update code that inspects framework `modelName` values. Consumer models can keep their generic names.

```typescript
import {publicFrameworkModelName} from "@terreno/api";

publicFrameworkModelName("TerrenoJob"); // "Job"
```

JWT recovery switches all default on. Set `legacyResetPasswordRoute: false` if your app owns `POST /resetPassword` but still uses `POST /auth/resetPassword`.

## Verification

- `bun run compile` and `bun run lint` at the app root
- Confirm `mongoose.modelNames()` includes `TerrenoJob` (and other `Terreno*` names) rather than colliding with your own `Job` / `Notification` / `Membership` models
- `cd <your frontend> && bun run sdk` after any `@terreno/api` route or model surface change
