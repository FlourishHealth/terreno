# 57.0.0-beta.1

First beta of the Expo SDK 57 line. Packages publish under the npm `beta` dist-tag;
`npm install @terreno/ui` (no tag) still resolves to the stable `0.x` release.

```bash
bun add @terreno/ui@beta @terreno/api@beta @terreno/rtk@beta
# optional local-first data layer
bun add @terreno/syncdb@beta
```

## Upgrade Expo before Terreno

This line targets Expo SDK 57. Upgrade the app first, then install Terreno betas:

| Package | Version |
|---------|---------|
| `expo` | `~57.0.14` |
| `react-native` | `0.86.2` |
| `react` | `19.2.3` |
| `typescript` | `~6.0.3` |

Follow Expo's SDK 57 upgrade guide, then bump `@terreno/*` to `57.0.0-beta.1` (or `@beta`).
Run `npx expo install expo@latest --fix` at the app root, rebuild native binaries, then
`bun run compile` / `bun run lint`. Regenerate the OpenAPI SDK after any `@terreno/api`
surface change (`bun run sdk` in the frontend).

Terreno's version major now tracks the Expo SDK major. Stay on the latest `0.x` or `56.x`
packages until you are ready to move the app to Expo 57.

## `@terreno/syncdb` and TinyBase 9.5

This beta bumps `tinybase` to `^9.5.1` for Expo SDK 57 / `expo-sqlite` type compatibility.
Apps using `@terreno/syncdb@beta` should reinstall and re-run sync integration tests after
upgrading Expo.

## From `56.0.0-beta.2`

If you are already on the Expo 56 beta line, upgrade Expo to SDK 57 before moving to
`57.0.0-beta.1`. There is no in-place semver path across Expo SDK majors — treat this as
a new Expo upgrade plus a Terreno major bump.
