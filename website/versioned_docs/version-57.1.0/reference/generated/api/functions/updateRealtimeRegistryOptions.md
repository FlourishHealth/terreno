> **updateRealtimeRegistryOptions**(`routePath`, `options`): `void`

Replace options on an existing registry entry (e.g. after TerrenoApp injects accessControl).
Matches by routePath; no-op if the route was never registered.

## Parameters

### routePath

`string`

### options

[`ModelRouterOptions`](../interfaces/ModelRouterOptions.md)\<`unknown`\>

## Returns

`void`
